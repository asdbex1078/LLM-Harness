# 汇编到机器码执行过程

汇编语言 → 机器码 → cpu 执行过程推理：

源程序（mov add sub mul div XXXX）→ 汇编语言 → 编译器 → 机器码
```
0000 0000 0000 0001
0000 0000 0000 0101
0000 0000 0010 0001
0000 0000 1000 0001
```
→ 符合 ISA 指令集 → 如何存储：硬盘 → 内存 → CPU（缓存）。

指令最终放到内存：每条汇编指令占若干 1byte；指令地址寄存器从 `0x00000` 开始顺序取指，根据指令的状态跳转执行 if 代码；指令太多复杂 → 按功能切分为指令段（代码段 A / 代码段 B），用 call A 相互调用。
