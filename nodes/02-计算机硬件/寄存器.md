# 寄存器

分类：[[通用寄存器]]、[[专用寄存器]]。

一个寄存器能表示多少 byte 数据呢？寄存器的位数和 cpu 的架构相关，即 cpu 的位数，32 位、64 位。

基本的存储单位可以是 1bit，如果我们每次寻址都只寻址 1bit，那么我将会频繁的进行寻址，导致效率降低。因为数据后续需要装入到寄存器参与运算，所以也不能够大于寄存器的大小。

**汇编就是操作寄存器**（见 [[汇编语言]]）。
