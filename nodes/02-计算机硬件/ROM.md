# ROM

只读存储器（Read-Only Memory）以非破坏性读出方式工作，只能读出无法写入信息。信息一旦写入后就固定下来，即使切断电源，信息也不会丢失，所以又称为固定存储器。ROM 内部的资料是在 ROM 的制造工序中，在工厂里用特殊的方法被烧录进去的，其中的内容只能读不能改，一旦烧录进去，用户只能验证写入的资料是否正确，不能再作任何修改。如果发现资料有任何错误，则只有舍弃不用。（可读不可写，断电不丢数据）

注：BIOS 芯片使用的就是 ROM。嵌入式微处理器用的就是 ROM，只用一点 RAM 对数据进行 CRUD。
