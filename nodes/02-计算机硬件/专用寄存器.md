# 专用寄存器

只用于某些特定场景：
- 状态寄存器 —— 状态机支持：跳转指令（根据指令的状态跳转执行 if 代码）
- 指令地址寄存器 —— 指向当前执行指令的地址（从 `0x00000` 开始）
- 栈顶寄存器 / 栈底寄存器 —— 支撑 [[栈帧]]，指令段进行跳转（方法调用）：call、ret
