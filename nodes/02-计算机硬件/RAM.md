# RAM

随机存取存储器（Random Access Memory）也叫主存，是与 CPU 直接交换数据的内部存储器。它可以随时读写（刷新时除外），而且速度很快。（可读可写，断电就丢数据）

类型：SRAM（晶体管）、DRAM（电容）。
