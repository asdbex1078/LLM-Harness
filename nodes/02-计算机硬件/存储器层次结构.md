# 存储器层次结构

存储器金字塔：CPU → L1 → L2 → 主存储器 → 硬盘 → CD-ROM/DVD。

典型计算机系统中的存储器层次（图 14-2）：
| 层次 | 容量 | 延迟 |
|---|---|---|
| 主 cache | 2K~1MB | 1ns |
| 二级 cache | 256K~4MB | 20ns |
| 主存储器 | 1MB~1.5GB | 30ns |
| 硬盘 | 1G~200GB | 100 000ns |
| 磁带机 | 50G~10TB | 秒 |

随着层次的递减，相对应的存储成本也在下降，但访问的速度也在下降。
