# 总线

控制总线（CB）、地址总线（AB）、数据总线（DB）。CPU → 内存：控制读写 / 控制地址 / 读写数据。

三类总线的位数？通常与 cpu 的位数相等，以下为标准的：
- CB 的位数：控制种类 2^n
- AB 的位数：地址的数量 2^n
- DB 的位数：一次传输的位数

> 图中原备注"缺乏总线，后续将总线画进来"——此节点即补位。
