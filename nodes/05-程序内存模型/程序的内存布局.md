# 程序的内存布局

那么指令放到内存的哪里呢？如何进行存放？

此时就需要将内存按照功能进行分割为几个部分，指令段中的指令，必定有自己的数据，而这些数据是当前指令执行完之后需要销毁的，而又有些数据是指令之间共享的。那么此时只需要按照功能将内存存放的数据分割为：**指令段私有的数据 + 指令段共享的数据**。

高地址 → 低地址：
| OS | 栈 | 堆 | 数据内存 | 代码内存 |
- 动态分配：栈、堆
- 静态分配：数据内存、代码内存

堆和栈在外界看来就是同一片内存区域，所以规定栈内存从上往下，规定堆内存从下往上。

- 共享内存中的数据是如何共享的？→ [[堆内存]]（分配内存 0x00000，数据内存存/取）
- 指令流里的私有数据如何存储呢？→ [[栈内存]]（栈顶 / 代码段A(私有数据) / 代码段B(私有数据) / 栈底；连续内存 vs 不连续内存，用栈顶指针、栈底指针标记）
- 代码内存存放指令，而由于指令中可以写入数据（mov 1, 寄存器），所以这里也存放了数据，只不过这个数据嵌在指令中 → [[代码段]]
- 用 16 进制来标记内存地址：`0xffff ---> 0x0000` → [[内存地址]]
