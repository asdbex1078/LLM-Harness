# 栈内存

指令流动态分配私有数据，怎么分？栈底寄存器、栈顶寄存器，由于内存之间是连续的，且又有高低之分 → 我们的指令流中有定义了加减操作 → 按照栈内存的增长方向 → 加减操作即可。

结构：栈顶 → 代码段A(栈帧) → 代码段B 栈底地址 → 代码段B(栈帧) → 栈底。
