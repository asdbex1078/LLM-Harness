# C语言

屏蔽 cpu 的底层，面向更符合人类的思维方式进行编程，开发人员不需要了解 cpu 架构和计算机体系（抽象汇编语言对于 cpu 和内存操作）。

c 语言是最纯粹的语言，没有其他语法层面的优势，比如切片语法、守卫语法、lambda 语法、函数式编程、面向对象……
