# RISC

精简指令集。一条指令完成一个操作，cpu 的压力变小，编译器的压力增大，可以提高 cpu 的主频。

主要特点：定长指令、load/store 架构、软件/编译器做复杂操作。
1. ARM
2. RISC-V
3. MIPS

执行：多条简单指令 → CPU → 输出。
