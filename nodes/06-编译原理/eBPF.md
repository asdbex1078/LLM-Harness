# eBPF

BPF（Berkeley Packet Filter）伯克利数据包过滤器。是一个工作在操作系统内核的数据包捕获机制，他先将链路层的数据包捕获再过滤，最后提供给应用层特定的过滤后的数据包。

如果想在内核中添加一点东西，简直比登天还难，而且这个东西还是个虚拟机，BPF 已经在内核中添加了 vm。

那我们就对 vm 做点手脚，原来 BPF 中的 vm 支持一些操作数据包的字节码，我需要做更多的事情，那么就增加一些 BPF 的字节码和操作空间 ——> Extend BPF ——> EBPF ——> BPF

结构：应用程序 ⇄ 系统调用协议（int 0x80 sysenter）⇄ OS 内核 [ LLVM IR → BPF → 网络栈 ]。

**类比**：客户端浏览器 ⇄ http ⇄ 服务器端 [ VM ← 数据 ]。这个是我们常见的客户端和服务器端的通信方式，假设我们这个数据传输是个长连接，服务器不停的向浏览器推送数据，但在推送的数据包中有一些数据并不是客户端想要的，那我们该怎么办？vm 就是拦截浏览器不要数据的。客户端将要过滤的数据转化为 IR 语言，vm 运行 IR 过滤掉不需要的数据，之后在发送给客户端。
