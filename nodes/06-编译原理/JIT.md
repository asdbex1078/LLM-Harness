# JIT

JIT（时编译器 / Just-In-Time）。实现了编译原理的前端和后端，只不过在内存中动态的对语言进行编译。
- 优点：执行速度快（对源代码进行了高度优化）
- 缺点：启动速度慢，因为需要花费大量的时间进行编译优化

与 [[解释器]] 循环配合（解释执行 ⇄ 热点编译）。Graal Compiler 是用 Java 写的 JIT。
