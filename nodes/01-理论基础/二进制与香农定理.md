# 二进制与香农定理

香农定理：
1. 计算机的基础是 0 1
2. 计算机的一切都是由 0 1 组成的
3. 为什么需要二进制？为了方便计算机运算

电路 0/1 表示：0、1 之间的这一段是为了稳定，如何是以一个定值作分割，如果电压突变之间增大，就会 0 突然变为 1，会影响最终的结果。

MSG → `0001 0010`（将消息编码成二进制）。
