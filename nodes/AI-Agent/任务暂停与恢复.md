# 任务暂停与恢复

## 描述

暂停表示任务仍然有效，只是暂时不继续执行；终止表示任务不再继续推进。两者在 [[长程任务生命周期]] 上是不同的路径（PAUSING → PAUSED → RESUMING vs CANCELLING → CANCELLED）。

## 核心内容

暂停恢复至少需要保存：

- 当前任务状态和版本；
- 已完成步骤及产物引用；
- 下一步动作及其前置条件；
- 未完成请求和外部操作状态。

沙箱快照（如 Firecracker snapshot）只能解决执行环境恢复问题：文件系统、进程和依赖是否保留。它不能自动替代 Agent 业务状态、任务数据库、对话历史或外部系统状态。恢复长程任务时，必须同时恢复业务状态，并重新确认未完成的外部操作。
