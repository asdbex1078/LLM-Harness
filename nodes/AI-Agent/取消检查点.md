# 取消检查点

## 描述

[[harness]] 层应在固定位置检查任务的取消状态。检查点只能阻止“下一步动作”；已经交给底层服务的请求，需要使用该服务提供的取消接口、连接关闭机制或取消 token。两者不能混为一谈。

## 核心内容

```text
读取任务状态
  -> 调用 LLM 前
  -> 选择工具前
  -> 工具调用前
  -> 工具返回后
  -> 写入阶段结果前
  -> 进入下一轮前
```

对于流式 LLM 请求，客户端断开连接通常只能表达“不再接收结果”；服务端是否立即停止推理，取决于推理服务的实现，必须以该服务的官方文档和实测结果为准（例如 vLLM 的 stopping generation 是接口能力，不能从 Harness 层统一推断）。
