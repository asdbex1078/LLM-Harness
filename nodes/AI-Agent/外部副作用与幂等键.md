# 外部副作用与幂等键

## 描述

“Worker 进程结束”不代表外部操作没有发生。工具调用必须按副作用分类处理，否则取消和重试都会产生重复副作用。

## 核心内容

### 可安全取消的操作

本地计算、只读查询、可中止的网络请求。取消后可以直接结束，但仍需记录请求是否已经发出。

### 不可回滚或需要补偿的操作

发送消息、创建订单、修改数据、触发部署。此类操作必须：

- 在请求中携带幂等键；
- 记录 `intent_created`、`request_sent`、`result_received` 等事件（见 [[Agent事件日志]]）；
- 超时后先查询结果，再决定是否重试；
- 必要时进入补偿或人工确认状态。

这一条同时是 [[任务取消语义]] 收尾和 [[崩溃恢复]] 的前提：没有幂等键，就无法回答“外部操作到底发生了没有”。
